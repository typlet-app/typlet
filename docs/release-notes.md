**Typlet** replaces short triggers such as `:sig` with your full text, in any app — formatted text, today's date, fill-in forms, a quick search and a visual editor. 🇩🇪 Deutsch und English.

> [!IMPORTANT]
> This is a **beta**. It works, but expect rough edges, and please [report what you find](https://github.com/typlet-app/typlet/issues/new/choose). The installers are not code-signed yet, so Windows warns about an unknown publisher.

## 📥 Download

| System | File | Notes |
|---|---|---|
| Windows 10/11 (64-bit) | `Typlet_<version>_x64-setup.exe` | Installs for your user only, no admin rights. SmartScreen: **More info → Run anyway**. |
| Ubuntu, Debian and derivatives | `Typlet_<version>_amd64.deb` | `sudo apt install ./Typlet_<version>_amd64.deb`, then log out and back in once. |
| Other Linux distributions | `Typlet_<version>_amd64.AppImage` | `chmod +x`, then start it. Needs the one-time keyboard set-up from the [user guide](https://github.com/typlet-app/typlet/blob/main/docs/user-guide.md#installing). |

`SHA256SUMS.txt` lists the checksums of all files.

## 🚀 First steps

1. Start **Typlet**. The set-up assistant opens and lets you try the first snippet.
2. Type `:mfg` (German) or `:br` (English) anywhere.
3. Open the editor from the tray icon to create your own snippets.

Read the [user guide](https://github.com/typlet-app/typlet/blob/main/docs/user-guide.md) · [Anleitung](https://github.com/typlet-app/typlet/blob/main/docs/user-guide.de.md).
